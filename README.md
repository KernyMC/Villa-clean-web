# Villa Clean Web

Marketing site for Villa Home Detail — premium house cleaning for Austin's Westside homes.

## Stack

- [Astro](https://astro.build) (static output), Tailwind v4, vanilla TS per-component
- [Sanity](https://www.sanity.io) for photography (`studio/`)

## Commands

All commands run from the project root:

| Command                    | Action                                         |
| :-------------------------- | :---------------------------------------------- |
| `pnpm install`               | Install dependencies                            |
| `astro dev --background`     | Start the dev server in the background          |
| `astro dev stop`             | Stop the background dev server                  |
| `pnpm build`                 | Build the production site to `./dist/`          |
| `pnpm preview`               | Preview the build locally                       |

See `CLAUDE.md` for project conventions (design tokens, content locations, component patterns).
